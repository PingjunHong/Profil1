# Evaluating FineSurE for Dialogue-Based Summarization: A Case Study
This is a repository for the final course report for Profilierungsmodul CL 1 2024-2025.

### The structure of this projects:

**dataset:** toy dataset from SAMSum (in JSON format) are located in this folder:
- `original_summary.json`: the original summaries and transcripts from SAMSum
- `gpt_3.5_turbo_summary.json`: transcripts with summaries generated by gpt-3.5-turbo
- `gpt_4_turbo_summary.json`: transcripts with summaries generated by gpt-4-turbo
- `bart_summary.json`: transcripts with summaries generated by BART
- `fact_check_sample.json`: final dataset with annotation (factuality labels + factuality_types)

**results:** faithfulness scores for human generated summaries and generated summaries. Evaluation metrics: BertScore, Rouge Scores and FineSurE. 

The FineSurE results are retrieved by the code provided in the [FineSurE project repository](https://github.com/DISL-Lab/FineSurE-ACL24/tree/main):

```bash
cd CodeRelease
python finesure/fact-checking.py [input-path] [output-folder]

# example code for fact checking on sampled data.
python finesure/fact-checking.py dataset/frank/frank-data-sample-10.json result/fact-checking
```
